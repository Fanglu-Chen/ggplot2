# Single-cell marker expression dot plot

R Markdown reconstruction of the supplied marker-expression bubble plot. The
panel letter has been omitted and the original colour gradient has been replaced
with a blue–pale green–orange–deep red gradient.

## Files

- `single_cell_marker_dotplot.Rmd`: reproducible source.
- `single_cell_marker_dotplot.html`: self-contained report.
- `single_cell_marker_dotplot.png`: high-resolution figure.
- `synthetic_marker_expression.csv`: synthetic cluster-by-gene summary data.

Synthetic values are reproducible with `set.seed(1031)`.
