# Regulatory genomic feature tracks

R Markdown reconstruction of the supplied multi-track regulatory genomics
figure. It uses new synthetic data and a teal, steel-blue, violet, coral and
ochre palette. The panel letter is omitted.

## Files

- `regulatory_genomic_tracks.Rmd`: reproducible source.
- `regulatory_genomic_tracks.html`: self-contained report.
- `regulatory_genomic_tracks.png`: high-resolution figure.
- `synthetic_candidate_elements.csv`: synthetic element-level scores.
- `synthetic_re2g_links.csv`: synthetic regulatory links.
- `synthetic_gene_models.csv`: synthetic gene model coordinates.

Synthetic values are reproducible with `set.seed(1031)`.
