# Temperature-dependent Raman spectra

R Markdown reconstruction of the supplied stacked Raman-spectra figure. The
panel letter has been omitted as requested.

## Files

- `raman_temperature_spectra.Rmd`: reproducible source.
- `raman_temperature_spectra.html`: self-contained report.
- `raman_temperature_spectra.png`: high-resolution figure.
- `synthetic_raman_spectra.csv`: synthetic stacked spectral data.
- `spectrum_parameters.csv`: peak and noise parameters.

Synthetic data are reproducible with `set.seed(1031)`.
