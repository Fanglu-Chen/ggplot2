# Tree-distance embedding ridgeline

R Markdown reconstruction of the supplied cell-ontology distance figure. Five
new synthetic distributions are shown with distinct colours, alongside compact
tree diagrams, a direct-mapping callout and adjacent significance brackets. The
panel letter is omitted.

## Files

- `tree_distance_ridgeline.Rmd`: reproducible source.
- `tree_distance_ridgeline.html`: self-contained report.
- `tree_distance_ridgeline.png`: high-resolution figure.
- `synthetic_embedding_distances.csv`: synthetic observation-level data.
- `density_curves.csv`: density values used for the ridgelines.

Synthetic values are reproducible with `set.seed(1031)`.
